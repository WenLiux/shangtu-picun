# 商图批存

> 作者：Wenl

Tampermonkey（油猴）本地脚本，在京东、天猫和淘宝商品详情页一键批量下载详情图，并支持天猫/淘宝 SKU 图片按规格保存。无需服务器，图片直接写入用户选择的本地文件夹。

## 一键安装

- [Greasy Fork 安装（推荐）](https://greasyfork.org/scripts/586245)
- [OpenUserJS 安装](https://openuserjs.org/scripts/wenl/%E4%BA%AC%E5%9B%BE%E6%89%B9%E5%AD%98)
- [GitHub Raw 安装（备用）](https://github.com/WenLiux/shangtu-picun/raw/main/shangtu-picun.user.js)

需要 Chrome 或 Edge，并提前安装 Tampermonkey。批量保存使用浏览器文件夹访问能力。

## 本地安装 / 开发版

1. 在 Tampermonkey 中选择“添加新脚本”
2. 将本仓库的 `shangtu-picun.user.js` 内容完整粘贴并保存
3. 登录对应电商平台后打开商品详情页；脚本完全在本机浏览器中运行

## 功能

- 在商品页右下角注入详情图按钮；天猫/淘宝额外显示蓝色 `SKU` 按钮
- 自动识别京东、天猫或淘宝商品页
- 京东扫描 `graphext` 端点，天猫/淘宝仅扫描页面的“图文详情”容器
- 排除商品主图、评价图、店铺推荐图等无关资源
- 深色预览面板，网格缩略图，点击可看原图
- **单张下载**：卡片右上角按钮，即点即存
- **批量下载**：只选择一次保存文件夹，后续图片自动写入同一位置
- **稳定下载**：3 路并发、失败自动重试 2 次，支持 JPG、PNG、WebP、GIF 和 AVIF
- **格式校验**：按文件特征识别真实格式，自动修正 CDN 内容协商造成的错误后缀
- **SKU 图片**：提取当前商品全部可售 SKU 图片，按“序号 + SKU 名称”命名
- **SKU 清单**：保存图片后自动生成 `SKU_manifest.csv` 和 `SKU_manifest.json`

## 使用

1. 打开支持的商品详情页：
   - 京东：`item.jd.com/*.html`
   - 天猫：`detail.tmall.com/item.htm?id=...`
   - 淘宝：`item.taobao.com/item.htm?id=...`
2. 下载详情图：点击页面右下角的红色按钮
3. 下载天猫/淘宝 SKU 图：点击红色按钮上方的蓝色 `SKU` 按钮
4. 预览图片，或点击“选择文件夹并下载”
5. 选择一次目标文件夹，等待全部图片保存完成；SKU 模式会同时写入 CSV/JSON 清单

首次批量保存时，浏览器会请求所选文件夹的写入权限。

## 技术原理

```text
京东 item.jd.com
  → in.m.jd.com/product/graphext/{skuId}.html
  → 提取 360buyimg 详情图

天猫/淘宝商品页
  → 等待页面渲染图文详情
  → #imageTextInfo-content / 兼容旧版详情容器
  → 仅提取容器内图片

天猫/淘宝 SKU 模式
  → 定位“颜色分类”规格组
  → 排除禁用/无图规格 → 读取页面已加载的 SKU 原图
  → 按 SKU 名称保存 → 写入 CSV/JSON 清单

统一流程
  → 去重 → 规范文件名 → 预览 → 选择目录 → 并发写入并校验
```

### 关键发现

| 发现 | 说明 |
|---|---|
| `.dpg` 格式 | JD 私有后缀，实质是标准 JPEG（Lavc 编码），直接改 `.jpg` 即可 |
| `graphext` 端点 | JD 移动版遗留页面，未做 SPA 改造。SKU ID 从 `location.pathname` 提取 |
| 两种图片路径 | `img/jfs/` 和 `imgzone/jfs/` 都可能出现，必须同时匹配（v1.0.1 修复） |
| 天猫详情容器 | 新版使用 `#imageTextInfo-content`，脚本同时兼容 `.desc-root`、`.descV8-container` 等容器 |
| 精确隔离 | 天猫/淘宝只读取图文详情容器中的图片，不扫描整个页面 |
| SKU 原图 | 从“颜色分类”规格节点读取当前页面实际加载的图片地址，不混入评价图和推荐图 |
| `GM_xmlhttpRequest` | 绕过 `item.jd.com` → `in.m.jd.com` 的跨子域 CORS 限制 |
| File System Access API | 用户选择一次目录后，将全部图片直接写入同一位置 |

## 隐私

脚本只在匹配的京东、天猫和淘宝商品详情页运行。详情图和 SKU 图片请求直接发送到对应平台的图片域名，所选文件夹仅用于本地写入，不上传文件或收集个人信息。
